# ADR-0005: Third-party library choices (licence-aware)

- Status: Accepted
- Date: 2026-11-07

## Decision
| Need | Choice | Why |
|---|---|---|
| Command/query dispatch | None: endpoints call module application services directly | MediatR now has commercial licensing; a dispatcher adds indirection without benefit at this size |
| Mapping | Hand-written mapping | AutoMapper now has commercial licensing |
| Test assertions | Shouldly | FluentAssertions v8+ is commercial |
| Validation | FluentValidation (Apache-2.0) | |
| Tests | xUnit 2.9, Shouldly; integration tests use a real SQL Server (local SQL Express or CI container), throwaway database per run | Testcontainers deferred: Docker was not available on the dev machine |
| API docs | Built-in `Microsoft.AspNetCore.OpenApi` + Scalar UI (dev only) | Contract snapshot committed at `docs/api/openapi.json`, enforced by a test |
| Telemetry | OpenTelemetry (Apache-2.0), OTLP exporter enabled only when configured | |
| Charts | TradingView Lightweight Charts (Apache-2.0) | **Requires attribution link**; record in `THIRD-PARTY-NOTICES.md` when added (Phase 2/3) |
| Frontend | React 19 + TypeScript + Vite 6, TanStack Query, React Router 7, Tailwind 4; types generated by openapi-typescript | Vite 6 rather than 7 because the dev machine has Node 20.17 (Vite 7 needs 20.19+). React Router replaces TanStack Router (simpler, no codegen). shadcn/ui components will be added when needed |

Every new dependency must have its licence checked and recorded before it is added.

## Amendments
- 2026-11-07: dispatcher, test infrastructure, router and Vite version updated during Phase 1 implementation (see table).
